# Owner review

This is a complete Anthropic-specific rebuild from the exact previous native Mobile App Builder v1.3.9. All 189 previous workflow IDs and 16 specialist role cards are retained as readable references behind 30 entry skills, eight lead agents and eight commands. Review the readable department index, original design resources and Actor portfolio, and the per-file migration report before relying on the edition.

The material product change is opt-in authentication: core has no declared connector or environment credential handling. Live Actor execution uses the optional declared research integration and an explicitly provided sensitive userConfig token. Core still supports public-source research, planning and user-provided data exports. Its owner-operated CLI guide is retained as an alternative and does not authorize the assistant to borrow installer credentials.

Publisher tooling is outside the install folders. Four original readable helpers remain in core because the workflows use them; they only print plans or inspect a bounded prepared catalog and cannot read credentials or call a service. No workflow capability or original image is silently removed. The host counts the eight commands together with the 30 skills, for 38 skill-like entries.

Local regression tests, full inventory/hash validation, skill/agent frontmatter checks, public audits, media decoding, official strict manifests and real native host discovery are required before the release. Receipt files record the results. Host model output, authenticated research execution, consuming-app device QA and actual directory approval remain separate gates; do not infer them from passing local checks.
