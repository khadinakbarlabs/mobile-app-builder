# Mobile App Builder Research

Optional technical research configuration for Mobile App Builder. The main product works without this connection, using public-source analysis or user-provided exports. Install and configure this only when you have an explicitly selected research account and need live collection.

The connection declares one HTTPS destination and a required sensitive configuration value. It does not read ambient credentials, start a local server or run a package launcher. The [privacy disclosure](PRIVACY.md) and manifest identify the exact service and data destination; technical service names belong there rather than product branding.

Read the [connection workflow](skills/research-connection/SKILL.md) for setup, provenance, permitted data and execution boundaries. Account configuration alone does not authorize paid runs. Select the exact research operation, source, limits and approved budget before collection. Leave the connection disabled when the host cannot collect sensitive configuration safely. Live account behavior must be verified separately from package validation.
