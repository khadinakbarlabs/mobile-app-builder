# Anthropic distribution

This edition is authored solely for Claude's native plugin format. Its installed root contains the complete Mobile App Builder agency. The repository marketplace lists this core and an optional authenticated research integration as separate installations. There is no portable/OpenAI/Cursor overlay in either installed root.

The previous product remains available in its upstream repository, with the last native v1.3.9 review held by Anthropic. This new v2.0.0 edition is not submitted, approved or live in Anthropic's directory. Repository publication, local validation, host component discovery, live connector behavior and directory approval are independent states.

Publisher tools, tests, source provenance, archive checks and review evidence live outside the installed folder. Do not download and execute publisher tools as part of ordinary user onboarding. For review, select the core plugin folder rather than the marketplace root. The optional research integration is reviewed independently.
