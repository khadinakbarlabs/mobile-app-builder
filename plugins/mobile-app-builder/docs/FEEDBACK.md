# Share feedback on Mobile App Builder

The installed plugin does not send usage events, chat transcripts or project files to its publisher. Feedback stays in your conversation and workspace unless you choose to send it.

If you want the maintainer to improve the plugin, [open a feedback issue](https://github.com/khadinakbarlabs/mobile-app-builder/issues/new/choose). Describe the job you were trying to complete, what the plugin did, the result you expected and whether the problem recurs. A short redacted example helps. Do not include keys, customer data, private repository contents or full chat transcripts.

Useful categories are: wrong workflow, repeated question, missing context, inaccurate research, incomplete implementation, failed verification, unclear report and scheduled-run noise. Confirmed recurring problems should become behavior tests before a release claims them fixed.
