# Distribution

Mobile App Builder supports iOS, Android and web development through readable workflows, specialist instructions and resources. Its repository marketplace lists the core plugin and an optional technical research connection as separate installations.

Current source release: 2.1.0. Source publication, component discovery, real account behavior, security scanning, reviewer approval and live directory availability are separate states. Confirm directory status in the submission portal; a GitHub release does not establish a live listing.

Publisher tools, tests, source provenance and review evidence stay outside the installed folder. Select plugins/mobile-app-builder as the directory submission path, rather than the repository's marketplace root. Optional technical connections are reviewed independently. Do not download publisher tools as part of normal onboarding.
