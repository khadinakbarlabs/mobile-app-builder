# grow-app

Apply [the context and reporting workflow](../docs/INTELLIGENT-WORKFLOW.md). Distinguish installs, first useful result and repeat value. If the user wants continuing monitoring, use the bounded [recurring-work recipes](../docs/RECURRING-WORK.md).

Read only the entry skills relevant to the request: [guide-paid-acquisition](../skills/guide-paid-acquisition/SKILL.md), [guide-organic-growth](../skills/guide-organic-growth/SKILL.md), [guide-retention-lifecycle](../skills/guide-retention-lifecycle/SKILL.md), [guide-analytics-experiments](../skills/guide-analytics-experiments/SKILL.md).

Review available analytics and current distribution; propose a measurable experiment, creative or SEO improvement; separate observed performance from forecasts.

Start from the context the user provides. Ask only for a missing fact that changes the next action; continue independent work. Preserve unrelated changes. Paid research, account operations, deployments and publication follow the user's actual authorization.

Finish with the result, verification evidence, limitations and next concrete action.
