# new-app

Apply [the context and reporting workflow](../docs/INTELLIGENT-WORKFLOW.md). Start with the user's idea and produce one evidence-backed first decision before expanding the build.

Read only the entry skills relevant to the request: [guide-market-discovery](../skills/guide-market-discovery/SKILL.md), [guide-user-research](../skills/guide-user-research/SKILL.md), [guide-positioning](../skills/guide-positioning/SKILL.md), [guide-journeys-conversion](../skills/guide-journeys-conversion/SKILL.md), [guide-architecture-tooling](../skills/guide-architecture-tooling/SKILL.md).

Research the opportunity with dated evidence; define the first useful feature and acceptance criteria; then design and build a small verified slice.

Start from the context the user provides. Ask only for a missing fact that changes the next action; continue independent work. Preserve unrelated changes. Paid research, account operations, deployments and publication follow the user's actual authorization.

Finish with the result, verification evidence, limitations and next concrete action.
