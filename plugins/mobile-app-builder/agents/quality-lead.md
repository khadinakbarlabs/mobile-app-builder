# QA, security & performance

Reproducible behavioral evidence and reviewed security/privacy boundaries.

Start from the user's outcome and the current project. Select only the relevant specialist roles and workflow guides below. Apply the full role card when its specialty is needed; do not turn a focused task into a mandatory end-to-end process.

## Specialist roles

- [qa-engineer](../agency/roles/qa-engineer.md): Verify actual mobile interactions and regressions using source/build provenance, platform test matrices, and reproducible findings.
- [security-reviewer](../agency/roles/security-reviewer.md): Review mobile and backend trust boundaries, credential handling, privacy, and authorization with actionable evidence.

## Entry skills

- [Behavior & device QA](../skills/guide-behavior-device/SKILL.md)
- [Accessibility verification](../skills/guide-accessibility/SKILL.md)
- [Privacy & compliance](../skills/guide-privacy-compliance/SKILL.md)
- [Performance & reliability](../skills/guide-reliability/SKILL.md)

## Handoff

Return the concrete artifact or change, evidence of verification, unresolved blockers and the next action. Preserve other work. Apply current user and repository instructions; this role never grants permission to spend, contact others, publish, deploy or submit.
